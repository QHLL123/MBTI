# MBTI 16 型人格测试

一个自包含的单文件交互式 MBTI 测试页。零依赖、零构建，直接打开 `index.html` 就能用。

## 在线使用

开启 GitHub Pages 后访问：<https://qhll123.github.io/MBTI/>

## 功能

- **48 题标准版 / 24 题快速版** —— 每个维度 12 题（含 6 道区分度更高的核心题供快速版使用），可在开始页切换
- **四维度倾向百分比** —— 外向 E / 内向 I · 实感 S / 直觉 N · 思考 T / 情感 F · 判断 J / 知觉 P，带条形图和「临界」标记
- **16 型完整解析** —— 昵称、一句话画像、核心特质、天然优势、容易踩坑、亲密关系里的你、顺手的环境、7 个工作方向标签
- **断点续答** —— 进度存在 localStorage，刷新页面不丢
- **键盘作答** —— `1`–`5` 直接选择，`←` 返回上一题
- **一键复制结果** —— 生成可直接粘贴分享的文本

## 计分规则

每题 5 级李克特量表（1 非常不同意 → 5 非常同意）。单个维度：

```
pct = (答题总分 - 题数) / (题数 × 4) × 100
```

`pct` 表示朝向前一个字母（E / S / T / J）的强度：`> 50` 取前一个字母，`< 50` 取后一个。

恰好五五开时，先用区分度更高的核心题重算一次以打破平局；仍然持平则记为 **X**（偏好未分化）—— 这是 MBTI 的正式处理方式，不硬凑结果。

## 使用

```bash
# 直接打开
start index.html      # Windows
open index.html       # macOS

# 或者起一个本地服务
python -m http.server 8000
```
